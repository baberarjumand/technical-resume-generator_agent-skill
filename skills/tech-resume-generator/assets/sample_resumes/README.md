# Sample resumes (optional)

This folder intentionally ships **without** the large PDF/PNG/DOCX corpus.

For density/layout reference while authoring a résumé, download the optional samples (~120 files, ~100MB+):

```bash
# from the skill directory
npm run download-samples
# or
python3 scripts/download_sample_resumes.py
```

Index: [`download_manifest.json`](./download_manifest.json).

Downloaded files are gitignored. **Never copy** names, schools, or bullets from samples into a user’s résumé.
