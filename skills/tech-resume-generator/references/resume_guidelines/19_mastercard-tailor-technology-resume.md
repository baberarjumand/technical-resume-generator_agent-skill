## 19.1 Seven tips (primary)

1. **Customize each application.** Don’t send one résumé everywhere. Highlight skills/experience that match **this** posting.
2. **Keywords from the JD.** Required *and* preferred. Make a list; use it to **guide** résumé content **where relevant** (not stuffing).
3. **Highlight relevant experience.** Work, projects, accomplishments for **this** role. **Quantifiable results.**
4. **Relevant projects.** Role + technologies + outcomes. Hands-on proof.
5. **Adaptability.** Show you learned and shipped new tools/methods — tech moves.
6. **Skills section.** Programming languages, software, operating systems. List what is **relevant to the role**.
7. **Portfolio or GitHub URL** on the résumé so they can see the work.

Close: proofread. Goal = interview.

## 19.2 Career-transition sibling (Nov 2023)

Recruitment-expert “makeover” for industry/role pivots:

- Research a similar JD (LinkedIn/Indeed/Google); talk to people in the target role
- **Skills inventory** on a separate doc; circle only what matches; uncircled = de-emphasize, drop, or consolidate
- **80/20:** ~80% of the page is target-role skills; 20% is the rest of the career
- Hiring managers scan **~6 seconds**
- Suggested order: **objective** (aligned to the target) → **bulleted skills summary** → chronological work with detail on the circled skills
- Projects / part-time / side hustles **only if they match** the next job
- 5-second self-check + network feedback
- Courses, bootcamps, unpaid side-gigs if the inventory is thin

This is **pivot chrome**. An experienced candidate already has SWE/lead/CTO work — don’t lead with an objective or a 20% “other career” dump.

## 19.3 Student tips, LinkedIn, AI, interviews

**Students/grads (tip 5):** customize; show adaptability via projects, courses, real-world use; points at this tech-resume article.

**LinkedIn glow-up:** photo, elevator summary, rich media, Open to Work, headline keywords, skills assessments. Photo is for **LinkedIn**, not the résumé (99: no photo on the PDF).

**[AI guidelines](https://careers.mastercard.com/us/en/ai-guidelines)** — follow if applying here:

| Stage | Their rule |
| --- | --- |
| Résumé / application | AI may **help articulate**; content must **genuinely** match skills/experience. Falsifying (self, someone else, or AI) → **disqualify** |
| Cover letter | Grammar OK; **own voice**, experiences, aspirations |
| Interview prep | Mock tools / industry research OK |
| Live phone/video | **No AI-written answers**. Camera on unless they say otherwise. Don’t record without approval |
| Technical assessment | AI only if **they invite it** with a named tool |

They may use AI (human in the loop) for JD drafts, outreach, scheduling, interview questions, Copilot notes. Not a claim that Workday auto-rejects PDFs.

**Interview tips:** know **every** résumé detail; “Why Mastercard?”; ask questions; behavioral + problem-solving; STAR for behavioral. Technical interviews ≠ classroom leetcode only.

**Mastercard Way (interview, not skills line):** Create Value, Grow Together, Move Fast — plus curiosity, collaboration, adaptability, integrity, structured thinking, growth mindset. Put those in **stories**, not a soft-skill dump.
