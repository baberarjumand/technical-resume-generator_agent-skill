## 18.1 Hub ATS + portfolios

ATS is **not** “only AI + keywords.” Also: job posting, comms, scheduling; **keyword rank**; **knock-out questions** on the application; filters (source, referral, geo); LinkedIn sourcing.

Jobscan-style ATS upload copy:

- No headers, footers, tables, columns, extra lines, aesthetics
- Keep a **plain-text `.docx`** for portals
- Exact JD keywords; **spell out and abbreviate** notable terms
- Simple section titles; chronological inside sections
- **Don’t** cram every keyword — humans still read it

Portfolios: Wix, Issuu, LinkedIn, WordPress, Weebly. All GT students should keep LinkedIn current (F500 sourcing).

## 18.2 Resume Career Guide (May 2026)

**Job of the résumé:** interview. Digestible in **15–30 seconds**. Living document. Use the **posting as the outline**. Strong verbs + JD keywords. Highlight relevant; de-emphasize the rest.

**Common section order (student):** Education → Experience → Skills → Research → Projects → Involvement. Optional: study abroad, coursework, honors, **objective**, **summary of qualifications**, additional.

**Heading:** name largest (not huge); phone; email; LinkedIn. Optional: GitHub, portfolio, **address**.

**Education:** full degree title (no abbreviations); GT name + location; GPA **if > 3.0**; anticipated semester. Optional: honors, study abroad, courses. Transfer school only if degree/certificate, significant major coursework, or involvement. **Drop high school after year 1.**

**Experience:** paid or unpaid. Usually **after education**, unless newer projects belong higher. Split headers when you have enough (Relevant / Healthcare / Data Analysis / Additional). Spell the **month** out. Most relevant bullets **first**. **Do not list tasks** — scope, impact, what you learned.

**SAIL** bullets: Skill · Achievement · Impact · Learned.  
Guide table: Task/responsibility → Actions → Result & purpose (event → 50 attendees / $ raised).  
Resume-101: **Task + Skill + Quantity + Result/Purpose** (not every slot required). **2–5** bullets. Present or past simple.

**Skills:** computers, lab, languages, certs. Categories by function. Weave into bullets — a skills line **alone is not enough**. Undergrad guide allows proficiency labels “if necessary” and even **skills you will learn next semester**. **Don’t** for an experienced candidate (inventing). MS/PhD checklist **forbids** expert/novice.

**Projects:** for thin work (first/second year, career changer). Class, independent, org. Don’t dump every project. Drop or shrink once industry fills the page. Checklist: **classroom projects only until first full-time job**.

**Leadership:** treat like experience. Aim for ≥1 leadership role by graduation (student chrome).

**Keep vs cut:** does it qualify you for **this** job, or take significant time? No → cut.

**Do / don’t (corporate résumé)**

| Do | Don’t |
| --- | --- |
| Master file of any length; cut per posting | Write before you know the target |
| 1–2 pages (private/corporate) | “I” in bullets |
| Bold / ALL CAPS / italics / lines for scan | References or “available upon request” |
| Margins **0.5–1"**; 11–12 pt | Slang; unexplained abbreviations |
| PDF (unless they ask otherwise) | Photo |
| Filename: name + type + company/role (`George Burdell_Resume-Microsoft Software Engineer`) | **Microsoft Word or Canva templates**; tables that trap text; plagiarize samples |
| Plain-text twin for ATS forms | Over-creative format unless the job is creative |

**Résumé vs CV:** industry 1–2 pages; CV unlimited (faculty, postdoc, national labs). No photo on either. Objective/summary OK on résumé, **never** on CV.

Grammarly for typos. Have Career Center critique.

## 18.3 MS/PhD checklist + GenAI (graduate hub)

**Checklist (use over the undergrad “Java next semester” line):** original format not a stock template; 0.5–1"; **1–2 pages**; 11–12 pt, ≤2 fonts; consistent; white space; name **16–20 pt**. Color/graphics only for design/architecture — ATS may skip graphics.

US: no age/marital/religion/politics/photos; no pronouns in bullets; no references line.

Header: city/state (country if applying abroad); **full street optional**; LinkedIn/portfolio strongly recommended. Nickname OK. GPA: **all degrees or none**. Consulting may want GRE/GMAT — omit for SWE. Unknown employer: one-line what they do. **2–4 bullets**. Skills: list tools; **do not** label expert/novice. Optional 2–3 line **summary** for experienced hires (quantified). Leadership/teaching recommended. 2–3 publications max on a résumé.

**GenAI toolkit (Sep 2025):** eight prompts — JD keywords, section names, bullets from CV text, polish, academic→industry, transferable skills, industry language, ATS+recruiter critique. Prompt 3/6 **generate** bullets. Use as editor (Yale/Harvard/woodworksio); rewrite anything the model writes. Not ResumeBoost auto-draft.

**Mary Buzz (OMS / experienced):** Experience → Education → Skills → Management skills → Volunteer → Interests. Nested **Systems Engineer II / I**. Personal Gmail. LabVIEW “Expert / Proficient / Experienced” — checklist forbids that. Dates `7/2020` not spelled months. Knitting/rowing — cut. Closest GT analog to the candidate’s **experience-first** order.

**Taylor Jacket PhD 2-pager:** education → skills → ML research (GRA + Amazon intern). Industry SWE still **one page**.

## 18.4 Cover letters

Hub: highlight reel, not a résumé dump; **why this company**; customize from the JD.

Guide: **submit even if optional**. Cover = **one page, ~4 paragraphs**. Résumé they still call **1–2 pages**. Outline Word is **3 paragraphs** (intro / 3 skills / close) — same family as Harvard. Named addressee (`Dear Full Name:`); avoid Hiring Manager / To Whom. Same header font as the résumé. `Mx.` in the Burdell sample.

99: cover **only if requested** (woodworksio). If written: Harvard 3-paragraph skeleton; don’t follow “always attach.”
