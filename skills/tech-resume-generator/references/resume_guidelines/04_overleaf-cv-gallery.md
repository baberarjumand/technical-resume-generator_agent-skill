# Source 4 — Overleaf gallery: LaTeX CVs and résumés

[Index](./00_README.md) · [Cross-source rules](./99_cross-source-rules.md)

- **URL:** [https://www.overleaf.com/gallery/tagged/cv](https://www.overleaf.com/gallery/tagged/cv)
- **Linked from:** UNC CV resources (“LaTeX templates and examples — CVs and resumes”)
- **Page type:** Template catalog, not writing advice
- **No PDFs downloaded** (live Overleaf projects, not static files)

**UNC’s implied use:** if you want a CV (academic) or a designed LaTeX resume, start from a maintained template rather than inventing class files.

Staff-selected examples named on the gallery page (for later if we typeset in LaTeX): Simple Hipster CV, AltaCV, customised CurVe CV, Friggeri-based variants, ReCeiVe (LuaLaTeX), Twenty Seconds CV forks, plus many more community templates.

**Caution for ATS / US tech recruiting:** several Overleaf CVs are **multi-column, sidebar, or heavily designed**. UNC’s own samples are one-column and conservative. Prefer UNC’s structure for industry SWE applications; use Overleaf when a PI/academic CV or a deliberately designed document is required.
